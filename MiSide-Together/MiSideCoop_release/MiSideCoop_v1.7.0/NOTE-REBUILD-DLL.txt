⚠️ ATTENTION — Le DLL inclus dans BepInEx/plugins/MiSideCoop.dll
================================================================

Le DLL embarqué dans ce ZIP est le build PRÉCÉDENT (v1.6.8/9, 174 KB,
buildé le 19/05/2026). Il NE CONTIENT PAS le fix `hasCtrl` v1.7.0.

Pour avoir un build v1.7.0 fonctionnel, recompile depuis les sources :

  cd src
  dotnet build -c Release

Le DLL frais sera dans :
  src/bin/Release/net6.0/MiSideCoop.dll
  (ou src/bin/Release/MiSideCoop.dll selon ta config)

Remplace BepInEx/plugins/MiSideCoop.dll par ce nouveau fichier AVANT
de distribuer le ZIP ou d'attacher le DLL à la Release GitHub.

Raison : l'environnement de build d'Emergent ne fournit pas le SDK
.NET, donc la régénération du DLL doit se faire sur ta machine.
